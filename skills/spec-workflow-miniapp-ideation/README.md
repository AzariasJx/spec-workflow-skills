# spec-workflow-miniapp-ideation

**微信小程序需求挖掘与 MVP 构思。** 从模糊想法到可落地的 MVP 方案，含变现模型和流量路径的前置思考。

## 什么时候用

- 想做小程序但不知道做什么
- 有方向但不确定值不值得做
- 方向已定，想设计具体 MVP
- **不用于**：开发/备案/审核等执行流程

## 命令

```
/spec-workflow-miniapp-ideation <需求描述>
```

## 三种模式

| 模式 | 信号 | 做什么 |
|------|------|--------|
| A. 找方向 | 不知道做什么 | 引导用对标法 + 痛点法系统性挖掘 |
| B. 验需求 | 有方向想验证 | 三条筛选标准 + 四步验证法 |
| C. 构思 MVP | 方向已定 | MVP 公式 + 四角度细化 + 变现 + 流量 |

## 核心方法论

- **对标法**：微信三个入口找已验证需求
- **三条筛选标准**：功能单一 + 场景清晰 + 无头部竞品
- **MVP 公式**：痛点 + 必然行为 + 即时正反馈
- **变现模型**：广告 vs 订阅 vs 双轨
- **流量路径**：小红书引流 + 微信搜索
